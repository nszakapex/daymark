## Brand-use notes

- **Meta:** The official page says logo usage requires approval through a Meta counterpart. It specifies a 12px minimum symbol height and clear-space guidance; Meta must not represent Facebook. This file is the official site's standalone symbol, not a reconstruction or a downloaded full logo kit.
- **Google:** [Current product-icon guidance](https://partnermarketinghub.withgoogle.com/brands/google/branding-guidelines/how-to-show-googles-brand/) directs users to the Partner Marketing Hub for permission and compatibility guidance. Keep the product identity explicit and the application's own brand more prominent. The [Analytics API branding policy](https://developers.google.com/analytics/terms/branding-policy) separately governs API implementations, including logo placement and linkbacks; the standalone icon supplied here does not establish compliance with that policy.
- **Shopify:** The official page permits considering the standalone bag when space is limited or the wordmark would be illegible. Keep its S white. The page also states that brand use must be expressly authorized in writing, must not imply endorsement, and web uses should link to Shopify.
- **Stripe:** The official kit's selected color is `#533AFD`; preserve it. The newsroom says blurple is for light backgrounds. [Stripe Marks Usage Terms](https://stripe.com/legal/marks) govern use and prohibit misleading endorsement. No project-specific permission was obtained.
